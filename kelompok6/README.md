# Sticky Milk

## Navigasi
- `App.js` memuat `src/navigation/AppNavigator.js`.
- `src/navigation/AppNavigator.js` mengatur Native Stack untuk Login, Owner Tabs, dan Cashier Tabs.
- Owner: Dashboard, Produk, Transaksi, Laporan, Profil.
- Kasir: Kasir, Transaksi, Riwayat, Profil.
- Layar setelah login sengaja kosong dengan latar putih dan judul layar.

## Menjalankan aplikasi
```bash
npm install
npx expo start
```

Login masih berupa simulasi; pilihan peran hanya menentukan menu dan belum terhubung ke backend.
